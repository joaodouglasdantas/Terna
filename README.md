# Terna

Jogo de plataforma 2D em pixel art, com servidor para contas, saves na nuvem, ranking e
multiplayer.

Tudo do jogo está em [`jogo/`](jogo/) — como rodar, organização e API em
[jogo/README.md](jogo/README.md), deploy em [jogo/DEPLOY.md](jogo/DEPLOY.md).

```bash
cd jogo
npm install
npm run dev
```

Abra <http://localhost:5173>.
