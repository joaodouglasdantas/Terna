Chave da API Anthropic

Modo preferido (sem precisar de chave): se o projeto tiver um endpoint de sumarizacao no backend, configure-o em prd.endpoint_relatorio no JSON deste arquivo. Servido via http(s)://, o relatorio sera gerado por esse endpoint (a chave Anthropic fica no servidor). Nao precisa colar chave.

Voce esta vendo este modal porque nao ha endpoint configurado, o HTML foi aberto via file://, ou o endpoint bloqueou. Cole sua API Key Anthropic para usar o modo direto. A chave fica salva no localStorage deste navegador (nao e enviada a outro lugar) — voce cola UMA vez por browser e nunca mais precisa fazer isso. Obtenha em console.anthropic.com.
