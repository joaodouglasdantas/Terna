# .claude/hooks/_camadas.txt (3.5.7) — CLASSIFICACAO DAS CHAVES DE CONFIGURACAO DO HARNESS.
# harness:managed — versionado no mestre, chega a todo projeto pelo harness-sync.sh (a pasta hooks e nucleo).
#
# REGRA (medido 16/09/2026): 58 chaves de DECISAO do harness nao existiam no harness.env da Mariana e caiam
# no default do CODIGO, que nem sempre era o que o mestre declarava (HARNESS_DUELO_TIMEOUT 300 no mestre, 600 no
# script). Desde a 3.5.7 NENHUMA decisao do harness vive em variavel local:
#   (a) DECISAO DO HARNESS  -> hooks/_defaults.env (versionado, sync, UNICO lugar). Toda chave que NAO esta
#                              listada aqui e esta em _defaults.env e decisao. Definir uma decisao no
#                              harness.env / harness.env.local / ~/.harness.env.local e OVERRIDE CONSCIENTE:
#                              o doctor avisa, o sync reporta (ENV|decisao-no-projeto) e migra quando o valor
#                              e igual ao default (comenta a linha).
#   (b) DO PROJETO          -> .claude/harness.env (lista FECHADA abaixo: camada=projeto). Banco/URL/porta,
#                              lint, templates de worktree, RAG on/off, numeracao de migration, pastas.
#   (c) DA MAQUINA          -> .claude/harness.env.local e ~/.harness.env.local (camada=maquina): segredos,
#                              URLs/tokens de presenca e Beholder, runtimes, ollama, teto de frentes.
#   (d) AMBIENTE            -> kill switches e flags de processo (camada=ambiente): so no shell/CI, nunca
#                              versionadas; o doctor nao as cobra.
#
# FORMATO: chave|camada|permitido|obs
#   chave      nome exato ou padrao com '*' no fim (HARNESS_SKIP_*) — o padrao vale para todas as chaves com o prefixo
#   camada     projeto | maquina | ambiente | decisao
#   permitido  (so camada=decisao) csv das camadas onde o override e ESPERADO e nao gera WARN:
#              projeto | local (.claude/harness.env.local) | maquina (~/.harness.env.local)
#   obs        'obrig' = chave de projeto obrigatoria (o doctor FALHA se ausente) · 'segredo' = nunca versionar
# Uma chave de decisao SEM linha aqui = override em qualquer camada gera WARN no doctor e ENV|decisao-no-projeto no sync.
# Leitores: hooks/harness-env.mjs (classificar/resolver/drift), harness-sync.sh, harness-doctor.sh, harness-ui.mjs.
